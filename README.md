# Л/р 6 - интерфейс пользователя на React с Redux Toolkit и Axios

⬅ [Общее описание проекта и список веток](../../tree/main)

## Что реализовано в этом спринте

- Плитка и лента получают этапы жизненного цикла из [Go-веб-сервиса ЛР4](https://github.com/stepaperfil/Perfilev_RIP_2026_Backend/tree/lab4-auth-swagger). Если сервис недоступен, гость может просматривать этапы на mock-данных.
- В **Redux Toolkit** хранятся состояние входа, значения фильтра по максимальной цене за единицу и состояние выполнения запросов. Во время запроса кнопки блокируются.
- Запросы к методам этапов выполняются в **thunk** через клиент **Axios**, сгенерированный из Swagger. Вход и выход выполняются отдельными вызовами Axios.
- Вход даёт доступ к добавлению, публикации, лайкам и удалению своих опубликованных этапов. При выходе фильтр сбрасывается.
- **Vite** проксирует `/api` к Go-веб-сервису и `/tco-assets/` к MinIO. Изображение и видео по умолчанию лежат в проекте.

## Страницы

### Плитка - `/life_cycle_stages`

| Элемент | Что делает |
|---|---|
| Поле «Цена за единицу, ₽» и кнопка `›` | отправляет фильтр `max_price_per_unit`. Пустое поле показывает весь список |
| Карточка этапа | показывает фото, название, цену за единицу и число лайков. Нажатие открывает этап в Ленте |
| Кнопка «Удалить» | доступна создателю на его опубликованном этапе. После подтверждения удаляет этап из списка |

### Лента - `/feed` и `/feed/:id`

| Элемент | Что делает |
|---|---|
| Видео этапа | воспроизводится автоматически без звука |
| Сердце и счётчик | показывают число лайков. Создатель может поставить или снять лайк |
| Кнопка `→` | открывает следующий этап по порядковому номеру |
| «Подробнее» / «Скрыть» | показывает или скрывает описание этапа |

### Добавление - `/life_cycle_stages/new`

Доступно после входа. Если черновик уже есть, открывается форма публикации.

| Элемент | Что делает |
|---|---|
| Название, фото и видео, кнопка «Далее» | отправляет файлы и создаёт черновик |
| Описание, цена за единицу и порядковый номер, кнопка «Опубликовать» | публикует черновик и возвращает пользователя на плитку |

### Вход - `/login`

Форма отправляет логин и пароль в API. После успешного входа JWT записывается в Redux и `localStorage`, а пользователь возвращается на плитку. После F5 Redux начинает работу с гостевого состояния. JWT остаётся в `localStorage` для проверки в Postman.

### Нижняя панель

| Пункт | Что делает |
|---|---|
| Лента | открывает ленту с первого этапа |
| Добавление | открывает форму для создателя |
| Плитка | открывает список этапов |
| Вход / Выход | открывает форму входа для гостя или завершает сеанс создателя |

## Структура

```
src/
  main.tsx                         маршруты и подключение Redux
  store.ts                         состояние входа, фильтра и запросов
  api/Api.ts                       сгенерированный клиент Axios
  modules/
    lifeCycleStageThunks.ts        запросы этапов и переход на mock
    http.ts                       Axios для входа и выхода, заголовки и ошибки
    lifeCycleStagesApi.ts         локальная выборка этапов для mock
    mock.ts                       mock-объекты этапов
  pages/                          плитка, лента, вход и добавление
  components/                     карточка, фильтр и нижняя панель
  styles/                         стили приложения
public/                           mock-медиа и файлы по умолчанию
scripts/generate-api.mjs          генерация клиента из Swagger
```

## Запуск

1. Для работы с бэкендом запустите [сервисы ЛР4](https://github.com/stepaperfil/Perfilev_RIP_2026_Backend/tree/lab4-auth-swagger#запуск). Vite ожидает Go-веб-сервис на порту `8080` и MinIO на `9000`.
2. В папке фронтенда выполните:

```bash
npm ci
npm run dev
```

Приложение открывается на `http://127.0.0.1:3000`. Без бэкенда доступны плитка и лента с mock-данными.

Клиент `src/api/Api.ts` уже в репозитории. Если Swagger изменится, обновите его командой `npm run generate-api -- <путь-к-swagger.json>`.
