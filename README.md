# Л/р 5 - базовое SPA на React

⬅ [Общее описание проекта и список веток](../../tree/main)

## Что реализовано в этом спринте

- Одностраничное приложение (SPA) на **React + TypeScript**, сборщик **Vite**, компоненты **React-Bootstrap**, переходы между страницами через **React Router**.
- Внешний вид такой же, как у HTML-шаблонов ЛР1-2 в бэкенде: та же разметка и те же CSS-файлы (`src/styles/`) поверх стилей Bootstrap; `bootstrap_fix.css` убирает отличия, которые вносит Bootstrap.
- Интерфейс **гостя** по образцу ЛР1: страницы **Плитка** (список этапов с фильтром по цене за единицу) и **Лента** (один этап на весь экран).
- Приложение работает только на **mock-объектах** (`src/modules/mock.ts`), без бэкенда, БД и S3: фото и видео этапов тоже лежат в проекте (`public/mock/`).
- Изображение и видео **по умолчанию** лежат в самом проекте (`public/`) и показываются, если у этапа нет файла или файл не загрузился.
- Внизу навигационная панель из 4 пунктов: **Лента**, **Добавление**, **Плитка**, **Вход**. Доступны только Лента и Плитка.
- Без Redux и без React Context: данные хранятся в состоянии страниц (`useState`) и передаются в компоненты через props.

## Страницы

### Плитка - `/life_cycle_stages`

Список опубликованных этапов жизненного цикла в две колонки.

| Элемент | Что делает |
|---|---|
| Поле «Цена за единицу, ₽» | ввод максимальной цены за единицу для фильтра |
| Кнопка `›` | применяет фильтр: показываются этапы с ценой за единицу не больше введенной; пустое поле - все этапы |
| Карточка этапа | изображение, название, цена за единицу, количество лайков; нажатие открывает этот этап в Ленте |

Кнопки удаления этапа, как в ЛР2, здесь нет: это действие создателя, а в ЛР5 только интерфейс гостя.

### Лента - `/feed` и `/feed/:id`

Один этап на весь экран: видео этапа на фоне, информация поверх него. `/feed` - первый этап по порядковому номеру, `/feed/:id` - выбранный этап.

| Элемент | Что делает |
|---|---|
| Видео этапа | воспроизводится автоматически без звука; если видео нет - видео по умолчанию |
| Название | название этапа |
| «Цена за единицу» | цена за единицу этапа, ₽ |
| «Порядковый номер» | порядковый номер этапа в жизненном цикле |
| 💚 и число | количество лайков |
| Кнопка `→` | переход к следующему этапу по порядковому номеру; на последнем этапе ничего не происходит |
| «Подробнее» / «Скрыть» | показывает и скрывает описание этапа |

### Нижняя панель

| Пункт | Что делает |
|---|---|
| Лента | открывает Ленту с первого этапа |
| Добавление | недоступен (появится в ЛР6 после авторизации) |
| Плитка | открывает Плитку |
| Вход | недоступен (появится в ЛР6) |

Активный пункт выделен белым цветом и зеленой точкой.

## Структура

```
src/
  main.tsx                     маршруты приложения
  Routes.ts                    адреса страниц и подписи пунктов панели
  AppLayout.tsx                экран приложения и нижняя панель
  pages/
    TilesPage/                 страница Плитка
    FeedPage/                  страница Лента
  components/
    StageCard/                 карточка этапа в плитке
    PriceFilter/               фильтр по цене за единицу
    TabBar/                    нижняя навигационная панель
  styles/                      CSS из шаблонов ЛР1-2, стиль недоступных пунктов панели, поправки к Bootstrap
  modules/
    lifeCycleStagesApi.ts      получение этапов для плитки и ленты из mock
    mock.ts                    mock-объекты этапов
    format.ts                  формат цены
public/
  default-life-cycle-stage.jpg изображение по умолчанию
  default-life-cycle-stage.mp4 видео по умолчанию
  mock/                        фото и видео этапов для mock-объектов
```

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на `http://127.0.0.1:3000`. Бэкенд, БД и MinIO для работы не нужны.

## Технологии

- **React 19** + **TypeScript**
- **Vite** - сборщик и dev-сервер
- **React Router** - маршруты страниц
- **React-Bootstrap** + **Bootstrap 5** - компоненты интерфейса (Card, Form, Button, Navbar, Nav)
