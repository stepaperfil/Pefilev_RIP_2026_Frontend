# Расчёт стоимости владения активом (TCO) — фронтенд

> Учебный проект по курсу «Разработка интернет-приложений». Приватный репозиторий.

## О проекте

Дизайн-часть и (начиная с соответствующей лабы) клиентское приложение для расчёта совокупной стоимости владения активом (TCO).

| Термин задания | Что это в проекте |
|---|---|
| Услуга | Этап жизненного цикла актива (закупка, эксплуатация, техобслуживание, утилизация) |
| Заявка | Расчёт TCO — суммирование затрат по всем этапам |

## Технологии

**React + Redux + axios + React-Bootstrap** — начиная с лабы, где стартует фронтенд-трек курса.
